# Khối Sắc 3D — NCN Color Blocks

Route: `/xep-hinh/`. Free, single-player falling-block game integrated with the existing NCN navigation, shared account controller, announcements, theme, tool catalogue, search and library. The existing GitHub/Netlify deployment remains the host. No server game state, new service, account provider or public leaderboard is introduced.

## Game

- 10 columns × 20 rows, seven familiar four-cell shapes with deterministic seven-bag generation, collision detection, clockwise/counterclockwise rotations and bounded wall/floor kicks.
- 450ms landing grace, at most 12 input resets per piece; ghost landing, one hold/exchange per piece and three upcoming previews. There is no timed deadline per stage. Full horizontal rows clear together, with correct downward compaction.
- 100 stages across ten named color worlds. Stage goals rise from 4 to 13 rows, gravity gradually increases from 850ms to 157ms per row, and later worlds begin with up to four rows containing two-cell gaps. Each completed stage opens the next and starts a fresh board while carrying cumulative score.
- Clearing 1/2/3/4 lines earns 100/300/500/800 × stage, consecutive clearing pieces add combo points, and stage completion adds 500 × stage. Soft/hard drops award 1/2 points per cell. Complete the stage for one star, clear at least two lines together for two stars, or four for three stars. Replaying preserves the highest star result and unlocked progress.
- Mouse/keyboard: arrows move/rotate/soft-drop, X/Z clockwise/counterclockwise, Space hard-drop, C hold, P pause. Phone: tap rotates, drag sideways moves, downward swipe hard-drops. Visible touch controls remain available.

## Rendering and lifecycle

The board uses a high-DPI 2D canvas with cached bevelled faces, bright top facets, shaded sides, landing outlines, restrained board tilt and bounded color particles. This creates a 3D appearance without a WebGL dependency. The hero and catalogue artwork are locally drawn isometric SVGs. No external game imagery or textures are downloaded.

The renderer draws when state changes or particles are active. Device pixel ratio is capped at two. Reduced motion disables floating art, tilt, clear flashes and particles. Sound is synthesized only after opt-in, with no looping music or remote audio.

Validated browser-local version-one saves retain board cells, active piece/rotation, next-piece queue, hold state, PRNG state, score and stage. Completed-stage saves resume at the next stage. Best score, stars and unlocked stages are stored separately. A replacement run asks before discarding an unfinished run. Storage denial and malformed snapshots leave the game playable. Progress is local to the current browser, and does not synchronize through the shared NCN account.

Tab hiding, window blur, shared navigation/account/search and Help pause the game. Resume requires an explicit action. Fullscreen fits the board to both dimensions, supports a window-filling fallback, preserves play through rotation and keeps dialogs inside the fullscreen root. Screen Wake Lock reuses the tested Pikachu lifecycle helper, requesting only for a visible fullscreen/fitted view and releasing on exit, app switch or pagehide. The operating system may deny/revoke it; the UI reports the state without stopping play. Desktop verification cannot establish physical Android sleep behavior.

## Verification

```sh
node --test tests/ncn-xep-hinh.test.mjs tests/ncn-pikachu-awake.test.mjs tests/ncn-site.test.mjs tests/ncn-public-render.test.mjs
node tests/browser/ncn-xep-hinh.mjs
node tests/browser/ncn-layout.mjs
node tests/netlify-pack.mjs
```

Core tests cover all shape rotations, bags, collision/ghost, floor/wall kicks, hold, real four-line clears, completion transitions for all 100 stages, top-out, independent occupied-cell accounting and save validation. Browser fixtures cover actual input, touch gestures, pause/reload, shared UI, progress/unlock/stars, the final stage, blocked storage, native/fallback fullscreen, wake-lock grant/denial and responsive overlays. Browser fixtures use local server data only and never create real accounts or public scores. CI uploads the screenshots and result report.
