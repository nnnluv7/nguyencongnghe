# Pikachu NCN — Onet matching game

Public route: `/pikachu/`. A free, single-player browser game sharing the NCN navigation, theme, announcements and account controls. Scores and unfinished runs are browser-local; this game does not submit to the snake multiplayer leaderboard. Facebook remains a separate, unfinished integration.

## Rules and interaction

- Match identical non-empty tiles along orthogonal paths with at most two turns. One empty cell around the grid permits classic outside-frame paths.
- 80 tiles and 20 locally drawn SVG portraits. Desktop classic boards are 10 × 8; phone boards are 8 × 10. Daily boards always use 8 × 10 and the same seeded arrangement for the Vietnam date.
- Classic and Relax have five stages: fixed, down, left, up, right. Classic gives six minutes per stage; Relax has no deadline. Daily is one six-minute board.
- Every pair earns 100 points. Consecutive pairs within five active seconds build a multiplier, capped at five. Timed stages grant five bonus points per remaining second when cleared.
- Each stage has three hints and three shuffles. Manual shuffle costs 15 seconds in timed modes. A board with no legal pair automatically reshuffles for free, preserving every tile and its empty slots.
- Pause, help, shared account/navigation/search and leaving the tab freeze the timer. Returning requires an explicit resume. Saved runs resume from their stored board, score, stage, time and assist counts; the combo resets on reload. Storage denial or malformed data cannot prevent play.
- Sound starts muted and is synthesized only after opt-in. Reduced motion follows the device preference and can be changed in Help. All portrait/cover/hero SVGs are local; there are no sprite-service dependencies.
- Keyboard: arrows move within the board, Enter/Space select, Esc clears selection, H hints, P pauses/resumes. Native fullscreen is offered where supported.

## Site integration

The canonical tool config, static initial configs/menus, homepage card order, catalogue seed, library, search, sitemap, public-page allowlist and redirects include Pikachu. `sync-site-config.mjs` now orders static homepage cards exactly as hydration does, preventing a new, taller game card from changing grid height during page load. The shared account controller now catches a blocked localStorage getter before reading its legacy display hint; Identity authorization is unchanged.

## Validation

- Node tests compare pathfinding with an independent breadth-first search for all 4,608 combinations of 3 × 3 obstacle masks and endpoint pairs; check reproducible boards, pair-count preservation, every gravity direction, complete playthroughs, reshuffle recovery, save validation and Vietnam midnight.
- Browser fixtures exercise real clicks and phone taps, all five stages, hints, shuffle costs, timer expiry, Relax, deterministic daily boards, pause/restore, shared UI, blocked storage, 320–1440 px layouts and portal discovery. Fixtures never create production accounts or write production game scores.
- Shared-account browser checks and the full shared-page layout suite are run after integration. Netlify archives are packaged using the production bundler.
