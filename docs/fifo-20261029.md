# FIFO labels — 29 October 2026

The FIFO route now has one purpose: prepare and print the 48 positions from the
supplied workbook. It uses the existing NCN navigation, account, appearance and
announcement modules, with a dedicated controller and stylesheet.

## Workbook behavior

- Eight columns and six rows, numbered left to right. Input row 16 corresponds
  to position 1 and input row 63 to position 48. Deselecting a position never
  moves another row's data.
- Date, color/capacity and the last four IMEI characters occupy three fixed
  lines. The workbook's MM/DD convention is the default; DD/MM, six trailing
  characters and the complete serial are available explicitly.
- A blank color inherits the preceding physical row's color, including across
  deselected positions. IMEIs remain text, preserving leading zeros.
- The scanner fills selected positions with no IMEI, advances without moving
  the document, and refuses to overwrite a full sheet.
- Paste accepts one IMEI column or color and IMEI columns, optionally with
  headers. Imports are applied only after review; overflow and ambiguous columns
  leave the existing draft intact. Clearing and importing have one-step undo.
- The provided XLSM schema reads K8:R13, K16:K63, N16:N63 and the date/visibility
  controls. Macro execution is not needed. The original workbook and its real
  identifiers are not included in the repository or website.

## Printing and storage

A4 portrait is the workbook default. Margins start at 3.97 mm left and 7.97 mm
top; position spacing is 24.34 mm horizontally and 26.81 mm vertically. A5
landscape and adjustable margins/spacing accommodate a different feed. Invalid
geometry or text that cannot fit legibly blocks printing until corrected.

The interactive preview and print sheet share one renderer. Position circles,
selection numbers, navigation and controls stay out of the printed output.
Preview cropping shows the label area; the printer receives the complete chosen
paper size. Date/color/IMEI visibility preserves the remaining lines' positions.

Drafts stay in `ncn:fifo:48:v1` on the current browser. The app does not send date,
color, pasted content, workbook bytes or identifiers to a server. Account access
continues to use the site's existing shared service.

## Startup

- External executable scripts on this route: 24 to 3; stylesheets: 12 to 3.
- Removed the obsolete FIFO renderer, its stylesheet, Blogger scaffolding,
  sharing overlays and unrelated guide images from the route.
- The Excel reader is an inert head declaration, fingerprinted by the normal
  build and fetched only after an Excel file is selected. CSV/paste/scanning do
  not need it.
- The app initializes independently of account and catalogue requests. It uses
  system fonts and avoids extra blur surfaces around the form and preview.

## Verification

- Unit coverage includes fixed sparse positions, inherited colors, date
  boundaries, CSV quoting, overflow, leading zeros, draft recovery and escaping.
- Browser fixtures cover scanning, line visibility, paste/import/undo, the real
  Excel reader, optional import of the supplied XLSM, 320–1366 px layouts,
  light/dark mode, storage denial, calibration and no identifier transmissions.
- The A4 and A5 PDFs each have one page. First/last slot coordinates are checked
  against the geometry, and rendered print output is inspected separately from
  the interactive preview.
- Existing legacy print artwork retains its baseline; FIFO is deliberately
  removed from that old artwork snapshot because this task replaces it.

Run `node --test tests/ncn-fifo.test.mjs`, then build and run
`NCN_BUILT_TEST=1 node tests/browser/ncn-fifo.mjs`. Set `NCN_FIFO_REFERENCE` to a
local copy of the supplied XLSM to include the original-file import check.
