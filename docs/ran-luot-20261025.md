# Rắn Lướt NCN

Public route: `/ran-luot/` (also supports `/ran-luot` and `/ran-luot/index.html`). Original Canvas artwork and mechanics; no Slither.io code, images, services or branding are copied.

## Play

- Solo arena against ten explicitly labelled AI snakes, with safe spawns, steering/avoidance, growth, body collisions, respawns and loot. Touching your own body is allowed. The arena boundary is always lethal.
- Mouse, arrows/WASD, or a touch joystick steer. Hold Shift/Space, left mouse or the boost button for replenishable-energy acceleration. Q or the phase button grants 1.15 seconds of body phasing with a 13-second cooldown.
- Consecutive pickups within 2.1 seconds increase the multiplier every six items, to ×5. An 18-item chain activates seven seconds of double points, with an 18-second activation lock. Magnet and one-hit shield pickups last eight seconds; close passes and player-caused takedowns earn extra points.
- The first world event begins at 20 seconds, then every 35 seconds: double-value bloom, a centre core bonus that refreshes phase, and a magnetic field. Core position appears on the minimap.
- A seeded daily challenge uses Vietnam's calendar date and ends at three minutes. Sharing preserves the challenge date. Initial layout is shared; AI responses diverge with player actions. There is no global leaderboard or network multiplayer. Top length is the current match's AI/player ranking.

## Website integration

Uses the existing shared NCN appearance bootstrap, Liquid Glass shell, floating navigation, account controller, public notice snapshot, search, theme, footer and visitor count. Account dialogs and menus pause the game; returning never resumes it automatically. The game works without waiting for authentication. Real signed-in credentials, VIP permissions and payment behavior are unchanged.

Registered in `config.json`, every embedded first-paint config/menu, the home tool cards, public library seed, fallback catalogue and sitemap. Run `node scripts/sync-site-config.mjs` after future shared config edits, then `node scripts/prepare-public-shells.mjs`. Both are idempotent. The shell allowlist admits only the game HTML; no new server or score-write endpoint is added.

Records, XP, cosmetic unlocks and audio/effect preferences use the browser-local `ncn-ran-luot-v1` key, explicitly described in the UI. Scores do not sync across devices or accounts. Skins confer no gameplay advantage. A storage failure keeps the game playable and displays a persistence notice. Sound starts muted and is synthesized only after a gesture. Reduced motion disables shake, lowers particles/glow and freezes the decorative preview movement.

The phone arena measures available space below the actual notice/header so both skill buttons fit the screen. Pointer capture, cancellation, window blur, visibility and orientation changes release held inputs. Canvas resolution is capped at 1.75×; food glows are pre-rendered sprites, collision checks use a spatial grid, and physics advances at a fixed 60 Hz.
